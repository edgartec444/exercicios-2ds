
# Biblioteca - Sistema de Empréstimos

Projeto desenvolvido para gerenciar empréstimos de livros
utilizando Node.js e persistência em arquivo JSON.

## Funcionalidades

- Listar empréstimos
- Salvar empréstimos
- Atualizar empréstimos
- Remover empréstimos

## Tecnologias

- Node.js
- JavaScript
- File System (fs)
- JSON
- Jest

## Como executar

Instale as dependências:

npm install

Execute os testes:

npm test

## Arquivo de armazenamento

Os empréstimos são armazenados no arquivo emprestimos.json.

A variável de ambiente ARQUIVO_EMPRESTIMOS permite
definir outro caminho para o arquivo.
